Install Dart Services

Check the container runtime, save .env, and start the simulator. This follows the Quick Start in the Dart Services Compose README.

Container runtime

Install one runtime, then leave it running. The repository is already on this PC, so the clone step is done.

Checking this PC…

Docker Desktop is paid for commercial use. Rancher Desktop is free. After Rancher installs, set Preferences → Container Engine to dockerd (moby). The containerd engine does not include Compose. Run only one of these at a time. Windows may ask you to approve the installer.

Simulator settings

Compose reads .env from the project folder. Saving here creates that file from .env.example and keeps the comments.

SDK version

Image tag for the simulator. The README lists sdk2 through sdk7.

Start

The first start downloads about 800 MB and can take several minutes. Later starts take seconds.

Build UI is at http://127.0.0.1:3002 after build-module-ui is running. Simulator ports are 12345, 3601, 502, and 12360/udp.
